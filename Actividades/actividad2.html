Actividad 2. Explicando código en C

Programa: Verificador de Mayoría de Edad

A continuación se presenta un fragmento de código escrito en lenaguaje C

Código original:


#include <stdio.h>

int main() {
    int edad;
    printf("¿Cuántos años tienes? ");
    scanf("%d", &edad);

    if (edad >= 18) {
        printf("Eres mayor de edad.\n");
    } else {
        printf("Eres menor de edad.\n");
    }

    return 0;
}

Explicación paso a paso:

Biblioteca estándar: La línea #include <stdio.h> le dice al compilador que incluya la biblioteca estándar de entrada y salida, la cual es necesaria para poder usar funciones como printf y scanf.

Función principal: int main() es la función donde comienza la ejecución del programa.

Variables y Entrada/Salida:
Primero, se declara una variable de tipo entero llamada edad.
Luego, printf imprime la pregunta en la pantalla, y scanf lee el número entero que el usuario escribe en la consola y lo guarda en la memoria de la variable edad.

Condicional If-Else:
El programa utiliza un if para evaluar si la variable edad es mayor o igual a 18 (edad >= 18).
Si la condición es verdadera, imprime "Eres mayor de edad.".
Si la condición es falsa (el else), imprime "Eres menor de edad. ".
